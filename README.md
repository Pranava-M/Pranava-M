**🧠 DSA Hand Gesture Game Hub** — `Python` `OpenCV` `MediaPipe` `Flask`
Classic algorithms turned into playable games, controlled by webcam hand gestures. BFS pathfinding, DFS traversal, QuickSort and backtracking Sudoku, with time and space complexity documented for each. Gesture recognition runs on MediaPipe's 21-point hand-landmark model.

**🪄 Magic Karpet** — `Python` `OpenCV` `NumPy`
Real-time invisibility effect. HSV color masking plus background frame substitution makes a colored cloth vanish from a live webcam feed, with six post-processing modes including ghost trails, glitch scanlines and thermal vision.

**🎬 CineDine (MovieBooking)** — `HTML5` `CSS3` `JavaScript`
Combined cinema ticket and restaurant reservation interface with an interactive seat-selection map, live availability checks and menu filtering.

**🖐️ Hand Gesture Volume Control** — `Python` `MediaPipe` `Flask` `PyAutoGUI`
System volume controlled by hand gestures through the webcam — open hand, fist and thumb-up map to volume up, down and mute via simulated key presses.
